# Delumenyu

> **谷博康的 3D 机械模型库** —— SolidWorks 参数化零件、装配体与工程图，附设计过程文档与实测数据。
> 3D mechanical models by 谷博康 — SolidWorks parts, assemblies & engineering drawings, with design notes and measured data.

## 这是什么

这里放我做的所有 3D 机械模型。跟"发几张渲染图"不同，每个项目是一个**可复现的完整工程包**：模型原件、工程图、设计说明，以及建模过程中实测回读的体积 / 包围盒 / 特征数。

判断一个模型"做没做对"，靠的是数字，不是"看着像"。

## 目录约定

每个项目一个顶层文件夹，内部固定结构：

```
<项目名>/
├── sw/         SolidWorks 模型原件（.SLDPRT / .SLDASM）
├── cad/        工程图（DWG / DXF / PDF）
├── doc/        设计文档（规格书、运动学、偏差登记、分件结果）
├── DELIVERY.md 交付说明：做完了什么、没做完什么、为什么
└── REPORT.md   实测数据：体积、包围盒、sha256
```

**为什么把"没做完什么"也留在仓库里**：机械设计的价值有一半在"我知道哪里没做到"。只展示成功、隐藏偏差的仓库，对同行没用。

## 每个项目要达到的标准

- [ ] 每个零件有实测回读的体积与包围盒，不是"应该是"
- [ ] 至少一张工程图（GB 图框）
- [ ] 有 STEP / STL 交换格式
- [ ] `DELIVERY.md` 如实登记未完成项与根因
- [ ] 报告里每个数字都能指到出处

> 说明：这套标准从下一个项目起强制生效。现有的柱塞泵还缺 STEP/STL 导出与另外 3 张工程图，见它的 `DELIVERY.md`。

## 怎么加新模型

1. 按上面结构建文件夹，项目名用中文原名（不用拼音缩写，别人搜得到）
2. 在「项目索引」表里加一行
3. 提交信息写清"新增：<项目名> <做了什么>"
4. 单个文件超过 50 MB 的不要直接提交，走 Release 附件，README 里给链接

## 工具链

建模走 SolidWorks 桥接（`sw_*`）与 dsh-cad 内核（`cad_*`）；尺寸校验一律用体积 / 包围盒对账，偏差百分比写进 `REPORT.md`。

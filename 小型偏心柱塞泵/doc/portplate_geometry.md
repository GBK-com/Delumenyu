# 配流盘 BP-05 腰型配流窗 — 最终几何（Lead 复算，v1.1 定稿）

单位 mm；原点 = 配流盘中心；+X = 0°，逆时针为正。
盘体 Ø64 × 10，中心孔 Ø16.5，键槽 4×2.5（+X 母线）。
腰型窗：内 R22.5，外 R29.5（径向宽 7，中径 R26）。
**包角各 160°，岛角各 20°，岛中心线在 α=0°(+X) 与 α=180°(−X)。**

## 相位依据（为什么岛必须跨 ±X 轴）
配流盘随轴转 θ，柱塞 i 在壳体方位 φᵢ，其见到的配流盘坐标 α = φᵢ − θ。
柱塞 i 的位移极值出现在 θ = φᵢ（外死点，α=0）与 θ = φᵢ+180°（内死点，α=180°）。
⇒ 三个柱塞的换向点**同时**落在 α=0 与 α=180，因此岛必须以 α=0/180 居中。
校验：φ=0/120/240 三条柱塞，两个死点均落在岛上，各留 10° 密封过渡。✔

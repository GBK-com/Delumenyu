## 3. 裁决与偏差台账（Lead 已裁定，均不再待办）

### A — 回程盘装不进 → **裁定：BP-04 改为「泵体上端封压盘」**
我的诊断成立，Lead 进一步证明其更严重（几何无解，非参数问题）：沉头螺钉要进 Ø24 偏心轮则孔只能在 R9、沉头 Ø8 占 R5~R13；而中心孔又必须 ≥Ø30 才能越过 Ø29 偏心轮包络 → 沉头孔落在孔内无材料；孔缩到 Ø20 又越不过 Ø24/Ø20 偏心段。
**裁定：BP-04 不随轴转，改为 Ø104×6 封压盘（装配 z 56→62，中心孔 Ø20，上表面球面 R40 凸于 Ø60 范围，3×沉头 Ø5.5/Ø10 @Ø88 0/120/240，下表面 Ø78 密封槽，M5×30 压紧）；回程力由 3 个柱塞弹簧独立提供，弹簧座仍在柱塞孔底 R48。**
→ BP-04 属 sub-plunger 写域，我未改动该件。

### B — M4 底孔破出 → **裁定：3 个孔直接取消，已在 BP-02 上执行完毕**
回程盘改壳体装后，偏心轮端面不再需要 3×M4，破出问题随需求消失。**BP-02 已删该特征并重存**（见 §1 变更项），其余尺寸一律未动。
> 一处数字校正：Lead 预估「26270.86 → ≈26066」，方向是反的——删除切除特征会**回填**材料。正确预期 = 26270.860261 **+** 203.430423 = **26474.290684**（实测正是此值）。孔体积比 3×π×1.65²×8 = 205.27 少 1.84，正是那 0.126 mm 破出所没切到的材料。

### C — 材料未赋 → **裁定：不追，作「已知偏差」**
两件 `material = null`、`density = 1000 kg/m³`（SW 默认水），故 `mass_kg`（0.026474 / 0.019619）**无工程意义**，不得引用为设计质量。桥接器无赋材料接口（`sw_edit` 只能写自定义属性），已确认属能力限制。材料在工程图明细栏（BOM）标注：BP-02 = 45 钢调质 HB220~250，BP-05 = ZQSn6-6-3 锡青铜。

### D — 未注圆角 R0.8 → **裁定：保持现状，不补**
**「未注圆角 R0.8 由图纸技术要求统一规定，三维模型不逐边实现，以免破坏键槽与孔口功能尺寸。」**
（偏心轴已做 C1×2 端倒角 + R1×3 轴肩圆角；配流盘两面各做 C0.5，覆盖两面全部外露棱边。）

### E — 表面质量无法建模
配流面 Ra0.4、平面度/平行度 0.005、腰型窗位置度 Ø0.05 等属图纸标注项，SW 实体模型不承载，须由 AutoCAD 子任务在零件图上标注。

### 备注（对其他 SW 子任务有用）
1. **`sw_build` 的 cut 默认沿 −Z 切除**（不是沿草图法向 +Z）。z=0 平面上的切除要显式 `reverse: true` 才向 +Z 切；反之从 z=−12 平面向 +Z 切也要 `reverse: true`。我第一版两处键槽就因此切反（只切掉 1 mm），已删重建。
2. 在**命名基准面**上画草图时，实体坐标必须给 `[x, y, z]` 三点式，只给 `[x, y]` 会报 `center must be [x, y, z]`。
3. SW 的 `top` 视图对 Z 轴零件看到的是**侧视**；要看盘面用 `front` 视图。
4. **`sw_build` 的 `delete` 只删「本桥接会话内建的特征」**：文档一旦关闭重开，旧特征就删不掉（报 `was not made by sw_build in this bridge session`）。要真正删特征只能在同一会话内删，或整件重建（`suppress` 会在树里留被抑制特征，不等于删除）。

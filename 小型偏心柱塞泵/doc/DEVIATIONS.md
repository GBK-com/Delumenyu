## D-01　弹簧 BP-07 为 8 圈环形叠片，非真螺旋扫描体
- **客户要求原文**：弹簧：扫描弹簧
- **实际交付**：Ø1.2 线径、Ø10 中径、自由长 17、8 圈。几何上由 8 个 `旋转`（torus，断面 Ø1.2 圆、圆心距轴 5）沿 Z 等距叠放构成，体积 284.24 mm³（与「8 × 单圈环体积 35.53」精确吻合）。
- **原因**：本会话可用的三条扫描路径全部失败，且经实测排除：
  1. `cad_sweep`（内部内核）：直管路径精确正确（Ø1.2×20 长实测 22.62 = π·0.36·20），但 1 圈螺旋只得 0.16 mm³、8 圈只得 1.30 mm³ → **该内核的扫掠不接受离开起始平面的路径**，螺旋属结构性不支持，不是点数问题。
  2. `cad_loft` 圆截面沿螺旋放样：33 截面与 65 截面两次均报 `sections too dissimilar` → 螺旋截面框架差异被判为过大，不可用。
  3. FreeCAD 执行器不可用（`FreeCAD was not found`）。
  4. 桥接器 `sw_build` 无 sweep/pattern 能力（已确认）。
  5. 桥接器 MCP 侧 `solidworks_build_round_sweeps` 规格 schema 无任何文档，试验性调用曾令 SolidWorks 进入 `command_in_progress` 卡死状态；为避免危及后续装配/干涉/运动仿真（共用同一 SolidWorks 实例），**主动放弃该路径**。
- **影响与可接受性**：弹簧在整机中位于柱塞孔内、被柱塞遮蔽；装配干涉检查、明细栏、图纸均按 8 圈弹簧标注，几何包络（Ø11.2 / 长 17）与真螺旋件一致。按 GB/T 4459.4，装配图中弹簧本就允许简化/示意画法。
- **如需真螺旋体**：在本地 SolidWorks 中用「扫描（Sweep）＋螺旋线」手工建一次即可，参数已在 `DESIGN_SPEC.md §3.7` 给全。

## D-02　SW 三维模型未赋予材料属性
- 桥接器无「赋材料」接口（`sw_edit` 只能写自定义属性）。所有零件 `material = null`、`density = 1000`，故 `sw_mass_properties` 的质量数值**无工程意义，不得引用**。
- 材料在**工程图明细栏**中标注（泵体 ZL104、偏心轴 45 调质、柱塞 GCr15 淬火、配流盘 ZQSn6-6-3、弹簧 60Si2Mn、标准件 8.8 级 / NBR）。
- 若需真实质量：在 SolidWorks 里对每个零件「编辑材料」一次即可，几何不需要改。

## D-03　未注圆角 R0.8 未逐边实现
- 三维模型上未做全局 R0.8。原因：键槽宽仅 4 mm、Ø3.3 孔口等部位，全局倒圆会吃掉功能尺寸。
- 处理：按客户技术要求「未注圆角 R0.8」在**图纸技术要求**中统一规定，由工艺保证；模型不逐边画。
- 未注倒角 **C1** 在主要外缘已实现（偏心轴、泵体外缘、端盖、回程盘）。

## D-04　配流油路为原理性表达，未做流道级校核
- 3 个 Ø5 轴向配流孔（@R26）与 2 个腰型窗的相位关系已严格计算（`data/portplate_geometry.md`、`data/KINEMATICS.md`），三柱塞换向均落在 20° 密封岛上。
- 但泵体内吸/排油口（2×M14×1.5）到配流面的具体钻道路径为工程示意，未做流阻/气蚀计算。
- 配流盘随轴旋转的实现依赖「键联接 + 端面贴配流面」的假设，未做端面压紧力与泄漏量计算。

## D-05　回程盘 BP-04 功能重定位为「上端封压盘」
- **客户原始功能理解**：回程盘 + 弹簧压紧柱塞于配流盘。
- **实际设计**：回程盘为泵体上端封压盘（Ø104×6），承担封闭中心油腔、球面自定心、3 沉头孔压紧；**回程力由 3 个柱塞弹簧独立提供**（弹簧座在柱塞孔底 R48）。
- **原因（几何无解的严格论证，见 `DESIGN_SPEC.md §3.4`）**：轴装式回程盘的沉头螺钉必须落在 R9 才能拧入 Ø24 偏心轮，沉头 Ø8 占 R5~R13；而该盘要越过偏心轮包络 Ø29，中心孔须 ≥Ø30（R15）→ 沉头孔整块落入孔内无材料；中心孔缩至 Ø20 又越不过 Ø24 偏心轮与 Ø20 偏心段。中间取值被两端夹死。
- **影响**：功能上等价（回程力不缺），但「回程盘」的形态与客户草图的直觉不同。

## D-06　客户技术要求第 1 条的语义说明
- 原文「配流盘与柱塞球面配合面研磨」**已一字不改写进全部图纸技术要求**。
- 但本设计为端面旋转配流，配流盘与柱塞球面之间**无直接配合面**。实际需要研配的是：配流盘两端配流面 ↔ 泵体下端配流面（Ra0.4、平面度 0.005、平行度 0.005）。
- 该条已作为「客户原话」保留；**若客户本意是别的结构型式，此条需回退重议。**

## D-10　泵体零件图用 1:1 而非 2:1
- **原因**：Ø104 零件两个视图并排在 A3 上需 416 mm，可用幅面只有 400 mm，**物理放不下**。
- `DESIGN_SPEC.md §9` 允许「2:1 或 1:1，按图幅适配」，故取 1:1，非偷工。

## D-11　泵体 1° 拔模角用引线文字标注，未用角度尺寸
- **原因**：`dimension_angular` 会把 1° 量成补角 179°，换标注位置无解，属 AutoCAD MCP 工具缺陷。
- 处理：以引线 + 文字「1°」标注，尺寸值正确、可读，但**不是 DIMENSION 实体**。若客户要求角度尺寸实体，需手工补。

## D-12　图框/标题栏落在 `TITLEBLOCK`/`TEXT` 图层，未落在 `08-图框标题栏`
- **原因**：`titleblock_apply_iso_a3` 不接受指定图层参数。
- 处理：`08-图框标题栏` 图层已建但空置；图框仍是原生工具生成的合规 ISO 7200 图框，只是图层归属不同。

## 0. 型式决定（Lead 决策，已向客户声明）

**径向柱塞泵**，3 柱塞 120° 均布，偏心轮驱动，**随轴旋转的端面配流盘**，弹簧回程，回程盘压紧。

决策依据：偏心机构只能驱动径向柱塞（轴向柱塞需斜盘）。客户同时要求「配流盘弧形腰型窗口」「回程盘+弹簧」「偏心轴两处不同偏心距」「键槽」，
唯一自洽解为：**工作偏心 e₁=2.5 驱动柱塞 + 平衡偏心 e₂=1.2 配重 + 键槽驱动旋转配流盘**。

### 已声明并接受的简化（交付时必须向客户说明）
1. **配流物理路径**为原理性表达：3 个轴向配流孔 + 2 个腰型窗随轴旋转实现相位切换；泵体内吸/排通道以钻孔示意，不做流道 CFD 级校核。
2. **回程盘**定义为「随偏心轮转动的柱塞轴向限位盘」，承担"球面自定心 + 柱塞防脱开"功能；回程力由 3 个径向螺旋压簧提供，回程盘与弹簧共同构成回程机构。
3. 客户技术要求原文「配流盘与柱塞球面配合面研磨」**原样保留在图纸技术要求中**（不改客户措辞）；本设计中配流盘为端面配流，实际研配面为配流盘配流端面与泵体配流端面。

## 1. 坐标系与全局约定

- **单位**：mm；角度 °；质量 kg。SW 通篇 `mm/deg`。
- **泵轴线 = Z 轴**，原点 O 在**泵体下端面（配流面）中心**。
- Z 正方向：从配流盘指向端盖（即"向上"）。
- 柱塞方位：**0°(＝+X 向)、120°、240°**（绕 Z 逆时针）。
- 工作偏心 e₁ 的偏心方向：**+X**；平衡偏心 e₂ 的偏心方向：**−X**。
- 所有回转体零件建模时**局部轴线取 Z**，装配时按 §7 坐标放置。

### 柱塞运动学（装配与运动仿真依据）
柱塞 i 的球心到泵轴距离 ρᵢ = Rc_eff + e₁·cos(θ − φᵢ)，其中
- `r_c = 12`（偏心轮半径 Ø24），`R_ball = 5`（柱塞球头 R5）
- **ρᵢ ∈ [14.5, 19.5]**，极差 = 5.0 = 2e₁ ✔
- 柱塞 i 的球心位于方位 φᵢ 的射线上，距原点 ρᵢ
- 柱塞沿其自身轴线（径向）移动，**位移量 δᵢ = ρᵢ − 17.0**（以 ρ=17 为零位），范围 ±2.5
